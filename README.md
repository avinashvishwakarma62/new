# For Mannu ♡

A mobile-friendly, 10-step romantic apology website with photos, animations, interactive notes, a gift reveal, virtual hug, and replay.

## Preview locally
Open `index.html` in a browser. Keep the `photos` folder next to it so the images load.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a new **public** repository, for example `for-mannu`.
2. Upload `index.html`, `README.md`, and the entire `photos` folder (preserve the folder names).
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then click **Save**.
5. Wait a minute or two. GitHub will show the website URL in the Pages section, usually:
   `https://YOUR-USERNAME.github.io/for-mannu/`

Music is a soft synthesized melody and starts only after the visitor taps the music button. The website does not collect or send responses anywhere.
